## 简介（VNDB 原文）

The game is set in the 5th sea-top special district, the Sumiyoshi Academic Centre.
Things seem somewhat strange today at Murakumo Academy, the only place you can learn Jindou.
The uniforms that were once unified are now all over the place, but the students don't seem find it strange at all.
It seems that a boundary has been set up all throughout the Sumiyoshi Academic Centre.
