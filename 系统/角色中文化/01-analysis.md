# 角色中文标题转换分析

## 数据概况

- 角色页面：15,507
- 有 VNDB 原文名：13,119
- 原文名含汉字：8,568
- 原文名含假名：5,940（与“含汉字”存在交集）
- 无原文名：2,388
- 有 VNDB 别名：4,327

## 目标

在不破坏已有链接的前提下，为所有角色页面增加中文显示标题。角色文件名、`entity_id`、VNDB ID 和现有 Wikilink 目标保持不变。

## 转换策略

1. `中文名修订.csv` 中的人工修订优先级最高。
2. 常见身份称谓采用语义翻译，例如 `Mother` → `母亲`。
3. 原文名含日文汉字时，先将日本新字体还原，再转换为简体中文；假名部分单独音译。
4. 纯假名或无原文名的角色，依据常见名词典与读音进行机器音译。
5. 罗马音、日文原名和 VNDB 别名写入 `aliases`，用于 Obsidian 搜索。

## 风险与质量标记

- `manual_override`：人工确认的中文名。
- `glossary`：常用称谓或固定词典翻译。
- `converted_original`：依据日文汉字转换，通常比纯音译可靠。
- `phonetic_transliteration`：机器音译，只是候选名，可能与中文圈惯用译名不同。

所有自动结果均标记 `title_status: machine_generated`，不声称是官方中文名。
