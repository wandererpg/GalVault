# VNDB 图片导入说明

批量导入脚本位于 `系统/工具/import_vndb_images.py`，用于获取作品封面和角色画像、压缩为 WebP，并把图片嵌入对应的 Obsidian 页面。

## 默认行为

- 作品封面保存到 `assets/covers/<VNDB ID>.webp`；
- 角色画像保存到 `assets/characters/<VNDB ID>.webp`；
- 作品页面增加 `cover_image` 属性和“封面”区块；
- 角色页面增加 `portrait_image` 属性和“角色画像”区块；
- 图片使用 WebP，默认质量为 80；
- 已存在的图片会被复用，失败项可以通过再次运行重试；
- 索引、清单和错误记录保存在 `系统/图片导入`。

## 运行方式

```powershell
python 系统/工具/import_vndb_images.py
```

测试少量条目：

```powershell
python 系统/工具/import_vndb_images.py --limit 5
```

只导入作品封面：

```powershell
python 系统/工具/import_vndb_images.py --kind works
```

重新查询 VNDB 图片索引：

```powershell
python 系统/工具/import_vndb_images.py --refresh-index
```

## 注意事项

VNDB 的角色接口通常只提供一张尺寸有限的人物画像，不提供游戏安装包中的完整角色立绘和表情差分。

图片版权归原权利人所有。将图片随知识库上传到 GitHub 或公开分发前，应确认图片来源的授权条件及平台规则。
