# 发行版合并与空作品页补全

## 结果

| 项目 | 清理前 | 清理后 |
| --- | ---: | ---: |
| 作品页 | 2,390 | 2,388 |
| 发行版页 | 11,878 | 1,000 |
| 只有名称、封面或作品关系的作品页 | 1,390 | 0 |

963 部作品的多个发行版合并，删除 10,878 个发行版页面。1,388 个空作品页从 VNDB 补全，另外 2 个没有可用资料的作品页删除。

## 保留规则

发行版按所属作品的 VNDB ID 分组，每组仅保留一个页面。先优先选择完整游戏，再比较已填写字段数、关联资料数、正文内容、链接数量和页面信息量。保留页的日期、平台和年龄分级仍属于该具体版本，不能据此推断所有版本。

其他版本的来源 ID、名称、日期、平台和年龄分级保存在 `consolidated_releases` 属性中；旧页面名称作为别名保留，和现存页面重名的别名除外。指向已删除发行版的链接重定向到保留页；和作品或角色重名时保留其链接含义。自动生成区块中的重复链接行合并。

原作品页上的 `release_count` 保留原始来源的统计含义，实际发行版页数量以清理后的文件为准。

## 空页补全与删除

空页指没有日期、评分等实质字段，没有会社、创作者、角色、声优、标签等资料，且没有自写正文的作品页。只有封面或关联作品链接不会视为已补全。已有具体资料但缺简介的页面不属于本次空页范围。

通过 VNDB 官方 Kana API 补充简介、发行日期、评分、时长、语言、平台、公司、创作者、无剧透标签、作品关系及可取得的角色配音关系。简介保留原文并标注来源与补全日期。对应实体已在知识库中时使用内部链接，否则使用 VNDB 外部链接，避免生成新的空页。

删除的作品：

- `v62430`（Danganronpa: Deadly Fever）：VNDB 有记录，但没有足够的正文或关联资料可补全。
- `v67916`：VNDB API 明确查无记录。

删除空作品页后，相关链接转换为显示文字。网络错误、限流重试失败或搜索匹配不确定不会触发删除。

## 验证与恢复

检查合并后每部作品最多有一个发行版页面，无指向本次已删除页面的残留链接，无剩余空作品页。维护工具的相关测试覆盖完整度排序、空页判定、链接重定向、名称冲突、来源记录保留、网络失败保留页面以及保留用户原有未提交修改。

执行前，将所有修改和删除页面的原始内容保存为知识库旁 `GalVault-maintenance-backups/consolidation-*.zip`，并检查 ZIP 完整性。备份包含原页面和操作清单，可按原相对路径恢复。文件级处理详情、实际备份路径及最终验证结果见 [report.json](report.json)。

维护工具：[consolidate_vault.py](../工具/consolidate_vault.py)。默认只检查，`--fetch` 查询 VNDB 并预演，`--apply` 验证及备份后执行。预演会更新本地 VNDB 缓存和报告，不修改作品或发行版页。
